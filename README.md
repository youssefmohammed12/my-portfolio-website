## Featured Projects

### Launchboard — [Read the case study](launchboard-case-study.html)

A personal workspace for tracking jobs, internships, and freelance opportunities discovered elsewhere, with application records, interviews, contacts, deadlines, and follow-ups in one place.

- **Technologies:** React 18, TypeScript, Vite 6, Tailwind CSS v4, Node.js, Express 5, Zod, TiDB Cloud Serverless, MySQL-compatible SQL, Vitest, GitHub Actions, Vercel
- **Highlights:** Opportunity dashboard and list/board pipeline, contacts, interview rounds, application-material metadata, activity history, calendar, deadlines, reports, CSV import/export, JSON backup/restore, and separate browser-only and authenticated API workspaces.
- **Engineering:** Shared TypeScript domain package, account authentication and recovery, database-backed sessions, CSRF protection, automated frontend/server tests, and CI builds.
- **Live app:** [launchboard-drab.vercel.app](https://launchboard-drab.vercel.app)
- **Repository:** Private for now.

Launchboard is a personal opportunity tracker, not a job board or freelancing marketplace. The local browser workspace and authenticated API workspace are separate and do not synchronize automatically.

### HealthBridge

A comprehensive hospital management and patient portal platform that connects patients, doctors, and administrators through a unified healthcare management system.

- **Technologies:** PHP 8+, MySQL / MariaDB, JavaScript ES6+, HTML5, CSS3, PDO, REST-style JSON APIs, Composer, Git
- **Highlights:** Patient portal, appointment scheduling and rescheduling, a four-step booking wizard, electronic medical records, prescription tracking, doctor workspace, hospital analytics, role-based access control, and audit logging.
- **Live demo:** [youssefhealthbridge.freehosting.dev](https://youssefhealthbridge.freehosting.dev/)
- **Repository:** [github.com/youssefmohammed12/hospital-project](https://github.com/youssefmohammed12/hospital-project)

- **Highlights:** Responsive SaaS landing page, custom product dashboard UI, interactive product demo, login and signup prototypes, pricing toggle, FAQ accordion, mobile navigation, keyboard-friendly modals, and reduced-motion support.

### NOVA Home

A full-stack furniture and home-decor e-commerce website for the Egyptian market, with product discovery, customer accounts, Cash on Delivery checkout, and an administrator portal.

- **Technologies:** PHP 8.1+, MariaDB / MySQL, PDO, HTML5, hand-written CSS, Vanilla ES2020+ JavaScript, Bootstrap 5.3.8, Swiper 14.3.0, Playwright
- **Highlights:** Search and filtering, product details, Quick View, wishlist, shopping cart, Cash on Delivery checkout, customer accounts and order history, product and category management, order-status workflow, store settings, session-based access control, CSRF protection, and prepared statements.
- **Customer demo:** [nova-home.fast-page.org/account/login.php](https://nova-home.fast-page.org/account/login.php)
- **Admin demo:** [nova-home.fast-page.org/admin/login.php](https://nova-home.fast-page.org/admin/login.php)
- **Repository:** [github.com/youssefmohammed12/Nova](https://github.com/youssefmohammed12/Nova)

NOVA Home is a portfolio demonstration. Its interactive demos use shared, mutable demonstration data, and checkout supports Cash on Delivery only.
