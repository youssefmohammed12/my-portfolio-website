Project 01

Launchboard

Full-Stack Opportunity Management Platform

Live App Case Study GitHub (Private)

Launchboard is a personal workspace for collecting jobs, internships, and freelance opportunities found elsewhere, then managing each application from first contact through interviews, deadlines, and follow-ups. It combines a browser-only workspace with an optional authenticated API workspace.

  • React 18
  • TypeScript
  • Vite 6
  • Tailwind CSS v4
  • Node.js
  • Express 5
  • TiDB Cloud
  • MySQL-compatible SQL
  • Vitest

Opportunity Workspace

  • Dashboard with pipeline summaries and upcoming activity
  • Create, search, filter, sort, and organize opportunities in list or board views
  • Track status, priority, deadlines, follow-ups, compensation, tags, and notes
  • Attach contacts, interview rounds, application materials, and activity history
  • Calendar, deadlines, reports, CSV export, and CSV import
  • Archive, restore, bulk actions, and full JSON backups

Platform & Engineering

  • Typed React frontend with a shared TypeScript domain package
  • Express API with request validation and ownership-scoped data access
  • Account authentication, database-backed sessions, CSRF protection, and account recovery
  • TiDB Cloud Serverless with a MySQL-compatible data layer
  • Automated frontend and server test suites
  • GitHub Actions CI and Vercel production deployment

Interface gallery — dashboard, opportunity pipeline & record details

Launchboard is a personal portfolio project, not a job board or freelancing marketplace. The browser-only and authenticated workspaces are separate and do not synchronize automatically. The source repository is currently private.
